# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to security@knackmentor.com rather than opening a public issue. Include what you found, how to reproduce it, and the impact. You will get an acknowledgement, and fixes are prioritized.

## Supported versions

The latest released version is supported. Older versions may not receive fixes.

See also: "Verifying a release" in the README for provenance and release-authenticity.

# Contributing

Thanks for your interest. Issues and pull requests are welcome.

## How to help

- Report bugs or suggest features via [Issues](../../issues) (templates provided).
- Send focused pull requests (one concern per PR).
- Improve docs and examples.

## Working on it

This is a single HTML file (`markdown-desk.html`). Edit it directly and open it in a Chromium browser to test. The user manual / spec is the regression checklist.

Please keep changes covered by tests where a test suite exists, and keep the change focused.

## Reporting security issues

Please follow SECURITY.md (report privately), not a public issue.
